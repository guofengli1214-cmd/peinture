# Peinture 多用户版 · 使用说明

> 本文档基于**当前实际实现**编写，如实标注「✅ 已可用」与「⏳ 待完善」。
> 架构：浏览器（仅持登录 Cookie）→ Nginx（静态前端 + 反代 `/api`）→ Node 后端 → MySQL（`mysql8` 容器）。
> 所有服务商 token 由**管理员分配**、**加密存于数据库、永不下发浏览器**，生成时由后端取用。

## 1. 用户角色

| 角色 | 能力 |
|---|---|
| **user（普通用户）** | 登录、生成/编辑图片、调整个人偏好（语言、生成参数、提示词、模型选择、存储设置）。**不能**自行配置服务商 token / 端点——由管理员分配。 |
| **admin（管理员）** | 普通用户全部能力 + 顶部「盾牌」管理入口：建/停/删用户、改角色、重置密码、**为任意用户分配服务商 token 与端点**（也包括给自己配）。 |

> 普通用户调用管理接口返回 403。

## 2. API / Token 配置指南 ★（核心）

### 2.1 在哪里配置
**只有管理员能配置**，入口在：**顶部盾牌图标（管理面板）→ 左侧选中一个用户 → 右侧「配置」区**。
（管理员要给自己配 token，也在这里选中自己的账号来配。普通用户的「设置」里没有 token 项。）

「配置」区包含：
- **服务商 Token**：6 个渠道各一个输入框，显示「已配置 / 未设置」状态（**不回显原始值**）。填入新值即“设置/替换”，多个 token 用逗号或换行分隔（后端会自动在多 token 间轮换、遇配额错误自动切换）；留空表示不改动。
- **OpenAI / Google 端点**：可填 API URL 与模型 ID。
- 改完点「保存配置」。

### 2.2 各渠道说明 · 申请地址 · 当前可用性

> ⚠️ 真实状态：下表是 6 个**内置渠道**。当前内置**直连**只实现了 HuggingFace；其余 5 个内置渠道的 token 可以保存，但“内置直连生成”尚未接入（Phase 6b）。不过你**现在就能用它们**——通过 §2.4 的「自定义/中转接口」按 OpenAI/Gemini 格式接入（OpenAI、Google、A4F、以及多数中转都是 OpenAI 格式）。

| 渠道 | 能做什么（接入后） | API Key 申请地址 | 是否需要 | 当前可用 |
|---|---|---|---|---|
| **HuggingFace** | 文生图（Z-Image Turbo/Z-Image/Qwen/Ovis/FLUX.1 Schnell）、图像编辑、图生视频、高清放大 | https://huggingface.co/settings/tokens （创建 Read 权限 token） | 可选（无 token 用公共配额，有限） | ✅ 文生图/编辑可用 |
| **Gitee AI** | 文生图（Z-Image/Qwen/FLUX 系列）、图像编辑、图生视频、文本优化 | Gitee AI 控制台 https://ai.gitee.com → 设置 → 访问令牌 | 必须 | ⏳ 待接入 |
| **ModelScope 魔搭** | 文生图（Z-Image/FLUX 系列）、图像编辑、文本优化 | https://modelscope.cn → 个人中心 → 访问令牌（My Access Token） | 必须 | ⏳ 待接入 |
| **A4F** | 文生图（Z-Image、Imagen 4/3.5）、文本优化（Gemini/DeepSeek/Qwen/GLM/Kimi 等） | https://www.a4f.co → Dashboard → API Keys | 必须 | ⏳ 待接入 |
| **OpenAI** | 图像生成 / 编辑（Responses API，端点+模型可配） | https://platform.openai.com/api-keys | 必须 | ⏳ 待接入 |
| **Google（Gemini）** | 图像生成（Gemini image，端点+模型可配） | https://aistudio.google.com/apikey | 必须 | ⏳ 待接入 |

### 2.3 推荐的最简配置（让生成立刻可用）
1. 用 admin 登录 → 盾牌进入管理面板 → 选中要用的账号（可先选 admin 自己）；
2. 在「配置 → HuggingFace」填入一个 HuggingFace token（去 https://huggingface.co/settings/tokens 创建，Read 权限即可）；
3. 「保存配置」；
4. 回到创作页即可稳定生成（无 token 也能用，但公共配额很容易用尽报“配额已用尽”）。

> 提示词优化（创作页“优化”按钮）走的是免费公共文本服务（Pollinations），**无需任何 token**即可用。

### 2.4 自定义 / 中转 API 接口（OpenAI / Claude / Gemini 格式）★ 已可用

除了上面 6 个内置渠道，你还可以**自由接入任意平台或中转（relay）的 API**，按请求格式分三类：
- **OpenAI 格式**：文生图（`/v1/images/generations`）、图像编辑（`/v1/images/edits`）、文本（`/v1/chat/completions`）。大多数“中转”都是这种。鉴权 `Authorization: Bearer <密钥>`。
- **Gemini 格式**：文生图 / 编辑 / 文本（`generateContent`）。鉴权 `x-goog-api-key`。
- **Claude 格式**：**仅文本**（`/v1/messages`），不能生成/编辑图片。

**归属与权限**：
- **全局接口**（管理员建）：所有用户可用，仅管理员可改/删。
- **管理员给某用户配的接口**：该用户可用、但只读（不能改/删）。
- **用户自建接口**：仅本人可改/删。

**在哪配置**：
- 普通用户/自己：**设置（齿轮）→「API 接口」标签** → 添加接口（自建的可编辑/删除；全局与管理员配的只读列出）。
- 管理员：**管理面板** → 不选用户时管理「全局接口」；选中某用户后在详情底部管理「该用户的接口」。

**添加接口表单**：名称、API 基础地址（如 `https://your-relay.com` 或 `https://api.openai.com`，带不带 `/v1` 都行）、格式、密钥（编辑时留空表示不改）、模型列表（每行：模型 ID + 显示名 + 能力多选：文生图/图像编辑/文本）、启用开关。保存后，这些模型会**自动出现在创作页/编辑页的模型下拉里**，生成时由后端用你存的密钥转发到对应接口（密钥加密存库、永不下发浏览器）。

> 视频暂不支持自定义接入。Claude 接口选了“文生图/编辑”能力也不会出图（格式不支持）。

## 4. 管理面板（管理员）

盾牌图标进入，全屏；左为用户列表，右为选中用户详情。

### 4.1 创建用户
左上「创建用户」→ 填用户名/密码/可选显示名/角色 → 「创建」。用户名重复提示“已被占用”，成功后自动选中。

### 4.2 账户管理（右侧「账户」区）
- **启用 / 停用**（停用即踢下线，不能停用自己）；
- **切换角色**（用户↔管理员，不能改自己）；
- **显示名称**（改后点保存图标）；
- **重置密码**（输入新密码 →「重置密码」，强制对方重新登录）；
- **删除用户**（二次确认，不能删自己）。

### 4.3 配置分配（右侧「配置」区）
见 §2。这是“给用户分配关键项”的地方：各渠道 token + OpenAI/Google 端点。

## 5. 创作页（Creation）★ ✅ 已可用

### 5.1 写提示词
- 顶部大框输入画面描述（中/英）；
- 「优化」按钮：自动把描述扩写成更专业的提示词（✅ 可用，免费 Pollinations）；
- 有历史提示词建议（本地）。

### 5.2 参数（控制面板）
| 参数 | 说明 |
|---|---|
| **模型** | 服务器模式下来自后端 `/api/v1/models`，即你被分配可用的模型。当前为 HuggingFace 5 个文生图模型，默认 **Z-Image Turbo**。 |
| **画面比例** | 1:1 方形、照片、横版、电影、竖版等。 |
| **种子 Seed** | 留空随机；填固定数字可复现同图。 |
| **步数 Steps** | 迭代步数，越大越精细越慢（各模型范围不同）。 |
| **引导强度 Guidance** | 部分模型（如 Z-Image）支持，控制贴合提示词程度。 |
| **HD** | 开启按更高分辨率生成。 |

### 5.3 生成与结果
1. 点「生成」(✨) → 加载 → 预览区出图；
2. **图片工具栏**：下载 / 复制提示词 / 详情(提示词·种子·步数·模型·尺寸) / 上传云 / 模糊开关 / 删除 / **Live(图生视频)** / **高清放大**；
3. 下方**历史画廊**为本次会话缩略图，可点选切换。

> 生成历史存浏览器本地（OPFS），**按浏览器存、不随账号同步**，约保留 1 天。

## 6. 编辑页（Editor）· ✅ 已可用（受 HF 配额限制）

“图 + 指令 → 新图”，基于 HuggingFace Qwen-Image-Edit：
1. 带入/上传图片；2. 可涂抹/框选编辑区、加参考图；3. 写编辑指令（如“背景换成海边日落”）；4. 执行得到结果，可下载/上传/继续编辑。
> 同样受 HF 配额限制，配额耗尽会提示，分配 HF token 可缓解。

## 8. 设置（齿轮图标）

按标签分页；**服务器是配置唯一来源**，个人偏好改动会自动（防抖）同步到后端，刷新/换设备仍在。

- **通用**：语言（中/英）、存储服务（本地 OPFS / S3 / WebDAV）、清除本地数据。
- **模型**：为「编辑 / 图生视频 / 文本优化 / 高清放大」分别选默认模型。
- **提示词**：自定义“优化”与“翻译”用的系统提示词。
- **Live**：图生视频默认参数（时长/步数/引导）。
- **存储（S3 / WebDAV）**：选了对应存储后出现。S3 填 endpoint/bucket/AccessKey/Secret/公开域名；WebDAV 填地址/账号/密码/目录。可「测试连接」。这是**你自己的**存储凭据，加密保存。

> token、服务商端点、服务模式**不在设置里**——属管理员统一分配的关键项，去管理面板配。

## 10. 常见问题

- **生成失败/提示配额用尽**：多为 HF 公共配额耗尽 → 分配 HF token，或稍后再试。
- **下拉只有 HuggingFace 模型**：其它渠道需管理员先配 token，且其后端接入属 Phase 6b（未完成）。
- **换浏览器历史图没了**：正常，历史存本地 OPFS，不随账号同步；设置/ token 才存服务器。
- **Live / 高清放大点了报错**：多为 HuggingFace 配额用尽 → 分配 HF token 后即可（这两项经后端走 HF）。
- **忘记管理员密码**：见本文 §0 或根目录 `.env`；或用数据库处理。

## 11. 运维速查（部署者）

```bash
# 仓库根目录执行
docker compose -f docker-compose.external-mysql.yml ps           # 状态
docker compose -f docker-compose.external-mysql.yml logs -f api  # 后端日志
docker compose -f docker-compose.external-mysql.yml up -d --build# 改动后重建
docker compose -f docker-compose.external-mysql.yml down         # 停止（数据在 mysql8，安全）
```
- 数据库：独立 `mysql8` 容器，业务库/账号均为 `peinture`（密码见根 `.env`）。
- 后端首启动自动建表 + 播种管理员（用 `.env` 的 `ADMIN_USERNAME/ADMIN_PASSWORD`）。
- 关键环境变量（根 `.env`）：`ADMIN_PASSWORD`、`APP_ENCRYPTION_KEY`（加密 token 的密钥，**勿丢**否则已存 token 无法解密）、`DB_PASSWORD`、`WEB_PORT`、`SESSION_TTL_HOURS`、`COOKIE_SECURE`（HTTPS 才设 true）。
